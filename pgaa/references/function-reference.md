# pgaa Function Reference

All functions live in the `pgaa` schema. Source: `pgaa/sql/pgaa--*.sql` (hand-written, authoritative migrations — not pgrx-autogenerated SQL).

---

## Table Creation

```sql
CREATE TABLE my_table (...)
USING PGAA
WITH (
    pgaa.storage_location = 'some-loc',  -- a storage location created via pgfs.create_storage_location
    pgaa.path             = 'some/path'
)
```

---

## Catalog Management

```sql
pgaa.add_catalog(
    catalog_name     VARCHAR,
    catalog_type     pgaa.catalog_type,  -- enum: 'iceberg-rest' | 'iceberg-s3tables'
    catalog_options  JSON
    -- iceberg-rest requires "url" (also accepts warehouse/token/oauth2.* fields)
    -- iceberg-s3tables requires "arn" (also accepts "region")
) -- returns TEXT; validates the connection before registering

pgaa.update_catalog(catalog_name VARCHAR, new_options JSON)              -- returns TABLE(name TEXT)
pgaa.delete_catalog(catalog_name VARCHAR, cascade BOOLEAN DEFAULT FALSE) -- returns TABLE(name TEXT)
pgaa.attach_catalog(catalog_name VARCHAR)
    -- returns TABLE (LIKE pgaa.catalog); starts continuous sync, polled at pgaa.metastore_sync_poll_rate_s
pgaa.detach_catalog(catalog_name VARCHAR, cascade BOOLEAN DEFAULT FALSE)
    -- returns TABLE (LIKE pgaa.catalog); cascade=true drops all tables the catalog manages first
pgaa.import_catalog(catalog_name VARCHAR, namespace_filter VARCHAR DEFAULT NULL)
    -- one-time import (vs. attach_catalog's continuous sync)

pgaa.list_catalogs()                                                            -- all registered catalogs + status
pgaa.list_catalog_tables(catalog_name TEXT, namespace_filter TEXT DEFAULT NULL) -- returns TABLE(schema_name, table_name)
pgaa.drop_catalog_tables(catalog_name VARCHAR, cascade BOOLEAN)

pgaa.test_catalog(catalog_name TEXT, test_writes BOOLEAN)
    -- tests connectivity to an already-registered catalog by name; NULL on success, error message on failure
pgaa.validate_catalog_connection(catalog_type VARCHAR, catalog_options JSON)
    -- tests a connection BEFORE registering (same options shape as add_catalog); NULL on success
```

## Storage Locations

```sql
pgaa.test_storage_location(name TEXT, test_writes BOOLEAN) -- returns TEXT (NULL on success); tests a pgfs storage location
```

Storage locations themselves are created via the `pgfs` extension (`pgfs.create_storage_location`) — see the `pgfs` skill.

## Table / Lakehouse Introspection

```sql
pgaa.list_analytics_tables()   -- PGAA-managed analytics tables: config, storage stats, replication status
pgaa.list_tiered_tables()      -- returns TABLE(schema_oid, table_oid, schema_name, table_name, partition_increment, retention, ...)
pgaa.get_all_analytics_table_settings()
pgaa.lakehouse_table_stats(relation regclass)
pgaa.lakehouse_table_stats_uncached(relation regclass)
pgaa.htap_table_stats_uncached(relation regclass)
```

## Task Orchestration

```sql
pgaa.launch_task(
    table_name    regclass,
    task_type     TEXT,
    task_options  JSONB     DEFAULT '{}'::jsonb,
    scheduled_at  TIMESTAMP DEFAULT NULL
) -- returns UUID
```

Background task state lives in `pgaa.background_task`.

---

## Query Execution & Engine Info

```sql
pgaa.spark_sql(query TEXT, catalogs TEXT[]) -- executes Spark SQL; requires pgaa.executor_engine = 'spark_connect'
pgaa.spark_sql(query TEXT, catalog TEXT)    -- single-catalog convenience overload

pgaa.pgaa_version()     -- returns TEXT: PGAA build/version + git commit hash
pgaa.seafowl_version()  -- returns TEXT: version/build/commit/optimization info for the configured Seafowl binary
pgaa.engine_version()   -- returns TEXT: version info from whichever engine pgaa.executor_engine currently selects
                         -- (Seafowl build/version metadata, or Spark/Java/Scala/OS info for Spark Connect)
```

## Key Tables

| Table | Purpose |
|---|---|
| `pgaa.catalog` | Registered external catalogs |
| `pgaa.table_mapping` | Maps Postgres tables to their backing lakehouse location |
| `pgaa.tiered_table` | Tables under tiering/retention management |
| `pgaa.background_task` | Task queue backing `pgaa.launch_task` |
| `pgaa.lakehouse_table_stats_cache` | Cached table statistics (TTL via `pgaa.lakehouse_table_stats_cache_ttl_s`) |

## GUC Parameters (selected — see SUMMARY.md for the grouped overview)

| Parameter | Description |
|---|---|
| `pgaa.executor_engine` | Selects the offload engine: Seafowl (default) or `spark_connect` |
| `pgaa.seafowl_url` | Endpoint for an external Seafowl process (when not using the embedded `autostart_seafowl_*` worker) |
| `pgaa.spark_connect_url` / `pgaa.spark_connect_extra_config` | Spark Connect endpoint and extra config, used when `executor_engine = 'spark_connect'` |
| `pgaa.metastore_sync_poll_rate_s` | Poll interval for continuous catalog sync started by `attach_catalog` |
| `pgaa.enable_metastore_sync_worker` / `pgaa.enable_maintenance_worker` | Enable the background sync/maintenance workers |
| `pgaa.max_replication_lag_s` | Replication lag threshold |
| `pgaa.autostart_seafowl_enable_metrics` / `pgaa.autostart_seafowl_metrics_host` / `pgaa.autostart_seafowl_metrics_port` | Prometheus metrics for the embedded Seafowl process |
